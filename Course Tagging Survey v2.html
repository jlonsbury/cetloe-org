High-Impact Practices (HIPs)

This step is three short questions: 1 — which practices are part of this course, 2 — which elements of high-impact learning are in place, and 3 — how much of the grade those practices carry. Questions 2 and 3 appear after you select a practice. If none apply, check the box at the end of the list and continue.

1

Which of these practices are part of this course?

Check every practice that happens in this course — as many as apply. They’re grouped by how much coordination they usually take, and each description tells you what counts.

2

Which elements of high-impact learning are in place?

Research identifies eight elements that make these experiences powerful. Check each element that’s in place for the practice(s) you selected above — the bullets under each element show what it looks like in practice. If you selected more than one practice, answer for them together. To count as a HIP, a course needs both required elements plus at least one more.

3

How much of the grade do these practices carry?

Pick one band: across everything you selected above, about what share of the overall course grade is tied to these High-Impact Practices? Then hit Continue.
